# Changelog

## 0.3.0.dev0 - 2026-10-11

- Added authenticated private-Git installation instructions, synthetic Jupyter
  and Colab notebooks, Conda and requirements recipes, VS Code configuration,
  a development container, and editor-neutral setup documentation.
- Added portable-asset validation and a CI notebook smoke test without adding a
  package-publishing step.
- Prepared a clean private-library sibling on 2026-10-12 without copying the
  frozen study, raw data, supplied documents, environments, or generated
  scientific outputs.
- Propagated configuration thresholds into generated blueprints, aligned
  decimal-comma coercion across screening and preprocessing, escaped multiline
  alerts as comments, and hardened JSON conversion for nullable scalar types.
- Added deterministic, code-generation, configuration, nullable-dtype, and
  numeric-string regression tests plus private inclusion/security policies.
- Added a tested compatibility shim for the historical
  `reverseda_ai.ReversedaAutonoma` namespace with a deprecation warning.
- Declared separate `sklearn`, `profiling`, `analysis`, `test`, and `dev` extras;
  retained `ml` and `report` as installation aliases for existing local users.
- Added a lazy optional profiling adapter and package-level debug logging that
  records shape/state only, never cell values.
- Added repeated formula-group sensitivity analysis across five seeds and two
  licensed UCI API smoke-test datasets.
- Added local build, installation, lint, coverage, documentation, and CI
  readiness gates. This is a development candidate, not a published release.

Versioning follows semantic-version intent: stable public-contract changes use
minor/major increments; this `.dev0` suffix marks an unreleaseable local review
candidate until the remaining human and remote gates are completed.

## 0.2.0 - 2026-10-11

- Renamed public brand/class/import to Reversede / `Reversede` / `reversede`.
- Preserved the 0.1.0 `reverseda_ai.ReversedaAutonoma` ZIP as immutable reference.

  stress, prescriptions, blueprint and API into focused modules.

- Added 15 behavioral tests, UCI source auditing, grouped splits, manual and
  profiling comparison, paired group bootstrap and executed notebooks.
- No package publication or release was performed.
